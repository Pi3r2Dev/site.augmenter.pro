# robots.txt — augmenter.pro
# Le `User-agent: * / Allow: /` ci-dessous suffit déjà à autoriser le crawl de
# tous les bots. Les blocs nommés qui suivent servent à deux choses :
#  1. l'opt-in/opt-out granulaire que certains acteurs exigent par token nommé
#     (ex. Google-Extended pour l'entraînement Gemini, distinct de Googlebot) ;
#  2. documenter explicitement notre posture bot par bot (autorisés vs bloqués).
# Les `Allow: /` redondants avec `*` sont volontaires : ils garantissent que ces
# bots restent autorisés même si une règle restrictive était un jour ajoutée à `*`.

# --- Portail client (/clients/) -------------------------------------------
# Documents remis à un client derrière un code d'accès : jamais crawlés. Le
# Disallow est répété dans CHAQUE groupe nommé ci-dessous : un crawler n'applique
# que le groupe le plus spécifique qui le concerne, donc un Disallow posé sous
# `*` seul serait ignoré par Googlebot, GPTBot, etc. La vraie protection reste
# côté serveur (code + cookie, X-Robots-Tag: noindex, Cache-Control: no-store).
User-agent: *
Allow: /
Disallow: /clients/
Disallow: /api/portal/
