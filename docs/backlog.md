# Backlog de boucle — maillage hiérarchisé du cluster Claude / Odoo / MCP

Source : audit du maillage du 2026-10-14 (session Claude Code, Search Console
sur 3 mois). Objectif : que les pages qui ont du poids chez Google transmettent
vers la landing `/serveur-mcp-odoo` et le workflow technique
`/blog/claude-code-odoo-workflow`, qu'aucun article de l'essaim ne soit orphelin,
et que le bloc « articles liés » cesse de renvoyer partout vers les trois mêmes.

Format : `- [ ] **ID [machine|humain]** -- tâche`. Une tâche qui **attend** une
autre reste `[machine]` avec `(apres ID)` en fin de ligne, jamais `[bloquee]` :
un `[bloquee]` posé à la main ne repart jamais seul. Seul le runner pose `[bloquee]`.

Ancres canoniques (une destination = une ancre stable, variantes grammaticales
tolérées seulement si la phrase l'exige) :

| Destination | Ancre |
| --- | --- |
| `/serveur-mcp-odoo` | « notre serveur MCP pour Odoo » |
| `/blog/claude-code-odoo-workflow` | « le workflow technique Claude Code + Odoo » |
| `/integration-mcp` | « intégration MCP pour PME » |

## Acquis

- Le juge ne lit que les `href` littéraux (`href="/x"` ou `href={"/x"}`) : un lien rendu depuis un tableau de données (`href={a.href}`, ex. `serveur-mcp-odoo/page.tsx` ~l. 825) lui est invisible → pour l'asserter, lire le fichier de données ou écrire le lien en littéral dans la phrase. (tour 1, `extractInternalLinks`)
- `public/llms-full.txt` cite des URLs d'articles dans le corps des sections : un `grep` du fichier entier dit « présent » pour un article absent de l'index → toujours borner la recherche à `## Index` … premier `---` (CRLF possible). (tour 10, 2 slugs ratés par le décompte de l'énoncé)
- Pas de `tsx` dans le repo : pour mesurer une donnée du catalog (alias `@/` compris) sans écrire de test, `npx vite-node --config vitest.config.ts <script.ts du scratchpad>`. (tour 5, répartition des articles liés)
- Une assertion de seuil (« ≥ N entrants ») se mesure avant de s'engager : `grep -rlE 'href=("|\{")/blog/<slug>("|#)' src/app src/components --include=*.tsx` donne les routes sources ; l'énoncé de MA-4 sous-estimait le manque de 3 liens. Depuis le tour 8, `sourceRoutes(href)` du juge fait cette mesure (src/app seul, un fichier compte pour la route de la `page.tsx` la plus proche, cible exclue). (tour 6, catalogue 1 entrant, logiciel 1 ; tour 8, assertion ≥ 3 sur les 8 ESSAIM)
- Une phrase de lien qui résume l'article cible (« ce qui manque », « trois formules ») se vérifie mot à mot contre ses h2 et ses puces : de mémoire, on prête à la page une promesse qu'elle ne tient pas, et le juge ne le voit pas. Vaut aussi pour une phrase existante qu'on réécrit. (tour 4, « traçabilité » absente des 5 manques d'`odoo-20-serveur-mcp-agents`, corrigée ; tour 11, « la page intégration MCP détaille les trois chemins » alors qu'elle renvoie vers `serveur-mcp-heberge-pme`, corrigée)
- `atelier-claude-code-dirigeant` est en **vouvoiement** malgré PROMPT.md (« landing = tutoiement ») : on écrit dans le registre trouvé dans la page, pas celui de la liste. (tour 9, « vous savez exactement à quoi vous attendre » l. 442)
