# Backlog de boucle — Discover et format « news » (ADR 0007)

Source : [ADR 0007](decisions/0007-google-news-discover.md), décidé par Pierre le
2026-10-14. La spec (six éléments) est dans l'ADR et fait foi. Ce backlog prend
la suite du run « maillage » (`docs/backlog.md`) : il ne démarre qu'une fois
ce run terminé, car les deux partagent `.boucle/`.

Format : `- [ ] **ID [machine|humain]** -- tâche`. Une tâche qui **attend** une
autre reste `[machine]` avec `(apres ID)` en fin de ligne, jamais `[bloquee]` :
seul le runner pose `[bloquee]`.

- [ ] **DN-3 [machine]** -- Générateur pur du sitemap news : `src/lib/news-sitemap.ts`, `export function buildNewsSitemap(articles: CatalogArticle[], now: Date): string`. Ne garde que `kind === "news"` dont `datePublished` est dans les 48 h précédant `now` (dates lues à minuit Europe/Paris, écrire la règle en commentaire), au plus 1 000, du plus récent au plus ancien. Titre échappé (`&`, `<`, `>`, `"`, `'`). Aucune URL → `urlset` vide valide. Tests (`src/lib/news-sitemap.test.ts`, `now` fixe) : un « news » à 47 h est inclus, à 49 h exclu ; un guide récent jamais inclus ; échappement d'un titre contenant `&` et `<` ; urlset vide quand rien ; namespaces présents ; ordre décroissant.
